# First-use and operator observations

An automated new-user run exercised the visible six-step Pen walkthrough in a fresh Chromium profile on the production build. Timing included screenshots, kernel measurements and file downloads. It finished in 145.915 seconds. No human participant took part. The 15-minute human target still needs a first-use study.

| Step | Observed behavior | UX observation | Evidence |
|---|---|---|---|
| Open the guide | The action bar says “Revolve the barrel.” An editable gold profile and X axis appear above it. | The Inspector simultaneously says “No feature selected.” The profile exists and the user can enter a length, so the empty-selection wording reads like an incomplete setup. | [Start profile](test-evidence/projects/guide/01-start-profile.png) |
| Revolve | Typing 4 in produced a 101.6 mm long barrel. “Revolve barrel” opened a second dialog where “Create feature” committed the change. | A new maker must connect the generic confirmation to the turn they just chose. The rendered hollow barrel provides clear feedback once it builds. | [First solid](test-evidence/projects/guide/02-revolved.png) |
| Insert parts | The cap appeared in silver and the history gained both thread features. The refill and clip action then switched workspaces. | The inserted refill is enclosed. The new four-body count is the visible confirmation that the internal part exists. | [Cap](test-evidence/projects/guide/03-cap.png) · [Assembly](test-evidence/projects/guide/04-cap-at-one-turn.png) |
| Turn the cap | 360° produced a visible 0.750 mm travel reading and a separate Save current pose control. | During assembly preparation the position field can already respond while Save current pose waits for the solver. The footer can say Ready before this workspace is ready to save. | [Pose](test-evidence/projects/guide/04-cap-at-one-turn.png) · [Initial assembly loading in a separate hinge run](test-evidence/projects/hinge/04-rotation-0-requested--5.png) |
| Check clearance | The guide action “Find clearance check” focused Full travel. The subsequent action ran the geometry check. | “Find” is a navigation command. The first click moves focus without starting a check. The final clearance message and numeric lower bound make the outcome verifiable. | [Verified clearance](test-evidence/projects/guide/05-full-travel.png) |
| Export the drawing | Drawing offers Print / PDF near the top, Download PDF below the sheet and Find PDF export in the guide. Download PDF completed the walkthrough and generated four A4 pages. | Two labeled PDF controls lead to different operations. On a short screen the download button requires scrolling. At whole-page fit several dimensions are small on screen. | [Sheet](test-evidence/projects/guide/06-drawing-ready.png) · [Completed export](test-evidence/projects/guide/07-finished.png) |

The keyboard-only run used command search, Tab, Enter and F2 to change a named parameter, rename a component and reorder its feature. Undo and redo restored the exact expected feature lists. The component list includes its timeline number in the accessible name. [Keyboard evidence](test-evidence/projects/power/review-1.jpg)

Seed 0x50454e35 exercised repeated canvas clicks, double-clicks and off-screen drags, sketch cancellation, window resizing, 50 rapid Undo/Redo pairs, reload during a draft, simultaneous editors, rescue export and close/reopen. Its JSONL log records the action, time, seed and coordinates. The committed 97 mm value survived a reload during an uncommitted 101 mm edit. With competing tabs, the 99 mm winner persisted and the losing tab exported its 103 mm draft.

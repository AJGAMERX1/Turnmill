## Observations from inspected images

- The SYS-001 assembly view shows the moving block at 45°, a visible gap, and the accepted named upper limit. The panel reports an angle error. The assembly sheet displays that same error in an otherwise empty page and disables its export buttons.
- The SYS-002 plate shows an open-ended, shallow transverse channel reaching both side faces. Turnmill reports Ready, mass 0.67 g and balance 5.02 mm. The requested two outer strips cannot fit the face at this orientation. An explicit placement warning would allow the maker to resize or reorient the graphic.
- The SYS-003 screenshot shows one solid and 100 history entries with the last feature selected. The timings come from the observed Ready transition, independent of the static screenshot.
- The SYS-004 screenshot shows Undo disabled with P2 X still at 10.02 mm. Redo remains enabled.
- Tiny and large block screenshots show the selected face in a light highlight and the remaining faces in brass. The constrained rectangle screenshot shows P3 and P4 at the same new Y of 5.4268 mm, maintaining a horizontal upper edge. The exact coordinates may vary slightly with the release browser layout.

## Reproduction

From the project root run `QA_SYSTEM_BROWSER=1 node tests/systems/run.mjs` against the QA production preview. Set `TURNMILL_URL` and `CHROMIUM_PATH` to override the defaults in the shared browser harness. `QA_FUZZ_MS` sets duration and `QA_SEED` chooses the first seed. System-only runs use `node tests/systems/run.mjs`. Given a saved failing fuzz chain, set `QA_FUZZ_REPLAY` to its JSON path and run `node tests/systems/fuzz.mjs`. Each failure is minimized against the same invariant with isolated journal state. The directed fixtures are deliberately limited to valid CAD edits of rectangular extrusions and complete revolutions; other feature chains are outside the present fuzz domain.
